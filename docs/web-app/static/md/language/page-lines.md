# Page lines

> **TO WRITE**
> - that `new line` ends the current page line and starts the next
> - that it also opens a fresh measure — you do not write `measure` after it
> - that anything declared `for each line` is restated on the new line
> - **that measures are numbered within their page line**, which is what span commands later rely on
