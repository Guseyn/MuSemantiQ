# Chords

> **TO WRITE**
> - that `chord` opens a note list and the notes go on the line below
> - **the blank line rule** — a chord's note list runs on until a blank line ends it. Without one the next unit is read as another chord member. This is the single most common mistake
> - that a duration goes on the `chord` line, not on the notes
> - that indentation is decoration: the parser ignores it
