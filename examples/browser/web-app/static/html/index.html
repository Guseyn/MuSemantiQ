MuSemantiQ

The Semantic Music Engine. You write music as plain text, and MuSemantiQ engraves it as an SVG score and plays it back as MIDI.

This page demonstrates the browser web components, served by npm run examples:browser.

  • Score
  • Playback
  • Score with playback
  • Editor

The components are customized built-in elements, which WebKit does not support. Use a Chromium-based browser or Firefox.

Every example below is a <template is="..."> holding MuSemantiQ source as its text content. On upgrade, each template replaces itself with the rendered component. They are all wrapped in a single <template is="msq-font-loader">, which loads the music, text and chord-letter fonts once and publishes them under the reference msqFontSources that the other components point at.
