the math of training

Every equation behind src/omr training, and nothing else. The crop, the forward pass, the loss, the backward pass, the nudge, and the check that keeps them honest. Each equation is the code it becomes.

Notation

a, zactivation, pre-activation — arrays; index triples like ai,j,c are column, row, channel
W, bweights, bias — learned numbers; Wp,q,c,k is filter k, window offset (p, q), input channel c
F, C, Kfilter size (3), input channels, number of filters
H, W, Ngrid height, grid width, batch size
pc, yprobability of class c; the true class of a sample
θall learned numbers together — every W and every b
λ, η, εL2 strength, learning rate, small constant
δ, gerror signal flowing backward; the gradient of one parameter

1The crop

One symbol, scaled to a fixed grid before anything else.

dst(x, y) = (1 / |R|) · ∑(u,v) ∈ R src(u, v)
(1)
shrink — the average of the source pixels the output pixel covers
dst(x, y) = (1−α)(1−β)·Q00 + α(1−β)·Q01 + (1−α)β·Q10 + αβ·Q11
(2)
enlarge — bilinear blend of the 2×2 neighbourhood Q; α, β are the fractional sample offsets

2The forward pass

Convolution, in the sum form and in the matrix form the code runs.

zi,j,k = bk + ∑p,q = 0..F−1 ∑c Wp,q,c,k · ai+p, j+q, c
(3)
convolution — out-of-bounds reads paper (padding = 0)
Z = P ŴT + 1 bT,    P ∈ ℝ(HW)×R,   Ŵ ∈ ℝK×R,   R = F2C
(4)
im2col — each window of the input becomes a row of P; the layer is one multiply
a = max(0, z)
(5)
ReLU
apooli,j,c = maxu,v ∈ {0,1}   a2i+u, 2j+v, c
(6)
max-pool, 2×2 — the winning index is remembered for the backward pass
z = W a + b
(7)
dense — every output on every input; before it, the maps are flattened: vec
pc = e zc − m ∑j = 1..K e zj − m ,    m = maxj zj
(8)
softmax — the shift by m is a constant; ∑ pc = 1

3The loss

LCE = − 1 N ∑n = 1..N log pn, yn
(9)
cross-entropy — only the probability of the right class counts
Lreg = λ ∑θ θ2
(10)
L2 — keeps the learned numbers small
L = LCE + Lreg
(11)
the total loss — the one number training pushes down

4The backward pass

One gradient rule per stage, in reverse order. For a single sample; a batch sums and divides.

δ(L) = p − onehot(y)
(12)
softmax + cross-entropy collapse to one subtraction
dW = δ aT,    db = δ,    da = WT δ
(13)
dense — blame on the weights, the bias, and backward through to the input
δz = δa ⊙ 1[z > 0]
(14)
ReLU — blame passes only where the gate was open
δz(2i+u, 2j+v, c) = δa(i, j, c)  at the remembered argmax
0  everywhere else
(15)
max-pool — the blame goes back to the cell that won

Convolution through the same im2col as (4). With D = the error reshaped to ℝ(HW)×K:

dŴ = DT P,    db = 1T D,    dP = D Ŵ
(16)
the layer is a matrix multiply, so its gradients are matrix gradients
da = col2im(dP)
(17)
each patch value returns to where it was cut from; where windows overlap, the blames add
∂Lreg ∂θ = 2λθ
(18)
the L2 share joins every weight gradient

5The nudge

Adam, per parameter, per step t. gt is that parameter's gradient from (12)–(18).

mt = β1 mt−1 + (1 − β1) gt
(19)
smoothed direction — β1 = 0.9
vt = β2 vt−1 + (1 − β2) gt2
(20)
smoothed scale — β2 = 0.999
m̂t = mt1 − β1 t,    v̂t = vt1 − β2 t
(21)
the correction for the first steps, when both start at zero
θt = θt−1 − η · m̂t√v̂t + ε
(22)
the nudge — η = 0.001, ε = 10−8

6The check

The backward pass is believed only where the finite difference agrees.

∂L∂θi ≈ L(θ + ε ei) − L(θ − ε ei) 2ε
(23)
central difference — meaningful only away from ReLU corners, where the loss has no derivative

7The count

How many learned numbers each stage owns.

|θconv| = K(F2C + 1),    |θdense| = out · in + out
(24)
weights and biases; for the 48×48 model — conv 160 + 4 640, dense 294 976 + 6 405 ≈ 306K
